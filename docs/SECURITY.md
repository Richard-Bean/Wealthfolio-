# 安全与隐私

## 核心边界

1. 不保存账号密码。
2. 不绕过验证码、短信验证、二次认证或平台风控。
3. 不抓取或改造私有个人账户接口作为普通数据 API。
4. 不上传用户财务原始数据、完整账单、截图 OCR 全文或身份证信息。
5. 不把敏感原始内容直接放入模型上下文。
6. 浏览器自动化只作为用户监督下的下载辅助。
7. 登录状态仅可保存在本机受控 Browser Profile 中。
8. 日志不得记录密码、Cookie、完整身份证号或完整账单正文。

## 原始数据分类

| 级别 | 示例 | 处理要求 |
|---|---|---|
| 高敏 | 姓名、身份证号、账号、完整账单、登录凭据 | 本地保存、最小化读取、禁止日志输出 |
| 业务敏感 | 交易、持仓、余额、收益 | 本地处理，只输出必要摘要 |
| 派生数据 | 标准化记录、校验结果、导入 CSV | 仍按财务数据保护 |
| 公开市场数据 | 基金净值、公开行情 | 可联网获取，但记录来源和日期 |

## Agent 上下文要求

- 优先传入结构化摘要、来源定位和校验状态。
- 不传入完整 PDF 或完整 OCR 文本。
- 不把身份证号、登录 Cookie、密码写入 prompt、日志或 manifest。
- manifest 中只保存文件路径、hash、字段摘要和状态。
- 如果需要模型判断，输入应经过脱敏和字段裁剪。

## 登录和浏览器

- 首次登录由用户人工完成。
- 后续只可复用本机 Profile。
- 登录失效时请求用户人工处理。
- 验证码出现时停止自动流程。
- 不模拟点击风控确认，不自动绕过安全控件。

## 文件安全

- 原始 PDF 和处理后的财务 CSV 必须加入忽略规则。
- 临时文件和失败产物不得混入正式导出目录。
- 正式产物采用临时文件写入后原子替换。
- 覆盖文件前确认不是上一次成功结果。
- 用户明确要求删除或覆盖时，先确认目标路径。

## 网络边界

允许：

- 公开基金净值和公开基金名称搜索；
- 用户明确授权的 Wealthfolio 本地或受控导入接口。

禁止：

- 私有个人账户接口抓取；
- 上传财务数据到第三方 AI 或云解析服务；
- 绕过平台访问控制；
- 在未说明用途时发送任何用户数据。

## 安全失败模式

```text
LoginExpired        → 停止并请求人工登录
CaptchaDetected     → 停止并请求人工处理
SensitiveDataFound  → 脱敏或阻止输出
UnauthorizedUpload  → 阻止网络请求
FileOverwriteRisk   → 保留旧文件并提示
```
