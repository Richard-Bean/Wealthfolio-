# Wealthfolio 中国金融同步连接器架构设计

本仓库为**架构设计仓库**，包含：

- `FinanceBot/` —— 金融账户同步到 Wealthfolio 的连接器项目（代码），结构见 `FinanceBot/README.md`；
- `wealthfolio_connection_v2.md`、`支付宝PDF直导入Wealthfolio_Addon技术设计.md` —— 架构与技术设计文档。

快速入口：`cd FinanceBot` 后运行 `python connectors/alipay/scripts/run.py`（详见 FinanceBot/README.md）。
